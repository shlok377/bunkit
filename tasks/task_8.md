# Task 8: Gamified & Visual Analytics Hub

## Overview
Create an engaging, expressive, and highly visual analytics dashboard. Replace bland text tables with interactive circular gauges, safe-to-bunk meters, attendance health scores, streak counters, and subject breakdowns.

## Key Deliverables
1. **Hero Attendance Dial & Health Score**:
   - Big, bold brutalist radial gauge displaying overall attendance percentage.
   - Target line indicator (e.g. 75% threshold) with green/yellow/red color bands.
   - Visual status banner ('Safe Zone', 'On the Edge', 'Danger Zone').

2. **Safe-to-Bunk Gauge & Catch-Up Meter**:
   - Gamified 'Bunk Wallet' card showing exact hours/classes safe to skip.
   - Urgent 'Recovery Plan' card when under target, displaying required attendance streak.

3. **Scenario Comparison Switcher**:
   - Instant visual toggle between:
     - Monthly Hourly Attendance (Scenario A)
     - Class Count Attendance (Scenario B)
     - Overall Semester Attendance
   - Side-by-side bar chart showing differences between hourly vs class count metrics.

4. **Subject-Wise Visual Breakdown Cards**:
   - Grid of subject cards with distinct assigned subject colors.
   - Mini circular progress dials for each subject.
   - Bunk capacity per subject (e.g., 'Math: 2 classes safe to bunk', 'Physics: 1 class needed').

5. **Day-of-Week Attendance Heatmap**:
   - Visual grid showing attendance performance by day (Mon-Fri), revealing worst bunk days.

## Acceptance Criteria
- [ ] All metrics rendered through rich visual components, zero unformatted plain-text dumps.
- [ ] Interactive toggle between Hourly, Class-Count, and Subject-Wise scenarios updates graphs instantly.
- [ ] Safe-to-Bunk and Catch-up cards display dynamic calculated values.
- [ ] High-contrast, responsive visual presentation with fluid chart animations.
